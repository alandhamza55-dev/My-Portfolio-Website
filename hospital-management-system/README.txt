ShifaCare Hospital Management System

How to open:
1. Open index.html in any modern browser.
2. The website uses HTML, CSS, JavaScript, Bootstrap, and browser localStorage.
3. For full CDN styling and icons, keep internet access available.

Files:
- index.html: Main website page
- styles.css: Custom responsive design
- app.js: Local database logic, forms, reports, permissions, audit actions, and localStorage saving

Saved browser data:
- Patients and medical history
- Visits and arrival queue
- Pharmacy POS receipts
- Finance and loan ledger
- Clinic purchases
- Reports and calculated totals
- Authorities and audit archive
- Language and currency preference

Note:
This is a front-end-only local system. It stores records in the current browser with localStorage. For a multi-user hospital installation, connect it to a secure backend database and authentication system.
