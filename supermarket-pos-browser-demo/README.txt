Supermarket POS browser demo

Open index.html. No PHP, MySQL, Apache, installation, or local server is needed.

Demo sign-ins:
- Admin dashboard: admin / admin123
- Cashier checkout: cashier / cash123

The demo keeps the project's Sorani Kurdish RTL sales interface and responsive layout. The cashier can search by product name or barcode, add items, adjust quantities, calculate VAT and change, complete a sale, and print the receipt. The admin dashboard supports product management, stock receipts, stock movement history, sales reports, date filtering, and CSV export.

Products, sales, purchases, and stock movements are stored in this browser using localStorage and persist on this device. The demo is not connected to the original database and its data is not shared. Clear the browser's site data for this file to reset it.
